# Hi, I'm Tayyaba! 👋

An **AI/ML Engineer** who builds intelligent systems that solve real-world problems, with a focus on **agentic AI, reinforcement learning, and automation for contact-center and customer operations**. I also run **Zenithra AI**, where I build AI services for businesses.

I've taken an AI QA and call-scoring pipeline from idea to production: it served **140 agents (onshore and offshore)**, handled **2,000–3,000 calls per week**, and automated QA on **95% of calls**, replacing manual scoring on each call. The platform supported a financial-services client whose customers included JPMorgan. I'm now rebuilding that work as an **agentic automation system with an RL-based scoring model that improves from feedback**.

I'm also interested in **secure, locally hosted AI** (Ollama), and in AI that helps people stay productive, organized, and sharp.
